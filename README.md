## 📱 项目介绍

本项目为微信小程序应用的前端工程，采用 TypeScript 强类型与 SCSS 预处理器开发，具备良好的工程化架构与清晰的代码组织。

### 🛠️ 目录结构
- `miniprogram/`: 小程序核心源码（页面、组件、静态资源）
- `typings/`: 微信原生 API 类型声明文件
- `project.config.json`: 微信开发者工具项目配置

### 🚀 运行与开发
1. 克隆本项目到本地。
2. 安装依赖：`npm install`
3. 使用最新版 **微信开发者工具** 点击「导入项目」，选择项目根目录即可开始预览与调试。

## 📱 Overview

Frontend codebase for a WeChat Mini Program built with TypeScript and SCSS, featuring modular component architecture and strict type safety.

### 🚀 Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`
3. Open WeChat DevTools, choose "Import Project", and select the project root directory.
